# キャラクター色相環ソート

自分が作成したTRPGキャラクターを、色相環とタグを使って眺め・探索するための個人用Webアプリです。
Node.js等のビルドツールを使わない素のHTML/CSS/JavaScript(ES5相当のバニラJS)で作られているため、
セットアップはほぼ不要です。

## 特徴

- 中央の色相環に、各キャラクターの「カラー」の色相(H)・彩度(S)を使って配置
  - カラーはキャラクターデータに登録した値をそのまま使用し、アプリ側で計算し直したりしません
  - 同じ/近い色でも重なりすぎないよう、簡易的な反発シミュレーションで位置を微調整します
- ホバーで簡易情報カード、クリックで詳細モーダル(編集・削除・「いあきゃらで開く」ボタン付き)
- タグによる複数選択の絞り込み(AND/OR切り替え可能)。絞り込み時は位置を変えずフェードで表示/非表示
- キャラクターの追加・編集・削除、カラーピッカー、タグの自由入力(既存タグ候補あり)
- データはブラウザのIndexedDBに保存(ページを閉じても保持されます)
- JSONエクスポート/インポートで丸ごとバックアップ・復元(画像もbase64で同梱されます)
- タブレット/スマートフォンにも対応(スマートフォンではホバーの代わりにタップで情報表示)

## 動作環境

モダンブラウザ(Chrome / Edge / Firefox など)であれば追加インストール不要です。
Node.jsやPythonは不要です。

## ローカルでの起動方法

ブラウザのセキュリティ制限上、`index.html` を直接ダブルクリックして開くと正しく動作しない場合があるため、
簡易的なローカルサーバーを経由して開くことを推奨します。以下のいずれかの方法で起動してください。

### 方法A: 付属のPowerShellサーバーを使う(追加インストール不要・推奨)

Windows標準のPowerShellだけで動く、依存ゼロの簡易サーバーを同梱しています。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\static-server.ps1
```

起動したら、ブラウザで以下を開いてください。

```text
http://localhost:8787/
```

ポート番号を変えたい場合は `-Port` オプションを付けてください(例: `-Port 9000`)。

### 方法B: Node.jsやPythonがある場合

Node.jsがあれば:

```bash
npx serve .
```

Pythonがあれば:

```bash
python -m http.server 8787
```

いずれも表示されたURL(例: `http://localhost:8787/`)をブラウザで開いてください。

## 使い方

1. 初回起動時はサンプルキャラクターが自動で登録されます(色相環の動きを確認するためのダミーデータです)。
   不要であれば1件ずつ削除するか、後述のインポートで丸ごと置き換えてください。
2. 右上の「＋ 新規キャラクター」から自分のキャラクターを登録します。
   - 「カラー」は、いあきゃらのキャラクターシートに登録している「カラー」の値をそのまま入力してください。
   - 画像は任意です。未設定の場合はカラーから自動生成したプレースホルダーが表示されます。
3. 色相環上のキャラクターにカーソルを合わせると簡易情報が、クリックすると詳細が表示されます。
4. 上部のタグをクリックすると、そのタグを持つキャラクターだけが色相環に残ります(複数選択可)。
   AND/ORの切り替えは絞り込みバー右側のトグルから行えます。
5. 「JSONエクスポート」で全キャラクターデータ(画像込み)をファイルに保存できます。
   定期的なバックアップを推奨します。
6. 「JSONインポート」でエクスポートしたJSONを読み込めます。
   既存データに追加/上書きするか、全置き換えするかを選べます。

## いあきゃらからの取り込み(ブックマークレット)

いあきゃらには公式APIが無く、このアプリはサーバーを持たない静的サイトのため、
URLを入力するだけで自動取得することはできません(ブラウザのCORS制限のため)。
その代わりに、**ブックマークレットでいあきゃら側から情報を取り出して貼り付ける**方式を用意しています。

1. 「＋新規キャラクター」を開き、「いあきゃらから読み込む」を展開します。
2. 「📥 いあきゃら取り込み」ボタンを、ブラウザのブックマークバーへ**ドラッグ&ドロップ**して登録します。
   (クリックしても動作しません。このアプリ上では意味を持たないリンクです。)
3. いあきゃらの自分のキャラクターシートページ(`https://iachara.com/view/xxxxx`)を開いた状態で、
   登録したブックマークをクリックします。名前・カラー・立ち絵・職業・年齢などがJSONとしてまとめられ、
   クリップボードにコピーされます。
4. アプリ側の貼り付け欄にペーストし、「反映する」を押すと各項目に自動入力されます。

**取得できるもの**: 名前、カラー、立ち絵、職業、年齢、性別、身長、その他シート上に表示されている項目(紹介文に追記されます)。
「出力→キャラ出力」に対応しているシートでは、それも自動でクリックして読み取ります。カラーコードは16進で直接取得でき(スウォッチの色から変換するより正確)、よみ・性格・好きなもの・嫌いなもの・備考なども紹介文に追記されます。
**取得できないもの**: タグ・シナリオ・HO(いあきゃらの公開シートページには表示されないため、引き続き手動入力が必要です)。

この機能は、いあきゃら利用規約第15条が禁止する「営利目的での複製・転用」には該当しない
(「ただし、ユーザー本人による投稿情報の利用は除く」と明記されています)、
**ユーザー本人が自分のキャラクターを自分のブラウザで読み取る**操作を想定しています。
他人のキャラクターページや、大量のキャラクターへの連続実行には使わないでください。

## データの保存場所と注意点

- データはブラウザ(オリジン: `http://localhost:8787` など)のIndexedDBに保存されます。
  ブラウザのキャッシュ/サイトデータを削除すると消えてしまうため、**JSONエクスポートでの定期バックアップを強く推奨します**。
- サーバーへの送信は一切行われません。完全にローカルで完結します。
- ポート番号やホスト名を変えて開くと、別のオリジン扱いとなり別データベースになる点にご注意ください
  (常に同じURLからアクセスしてください)。

## ディレクトリ構成

```text
trpg-character-archive/
├── index.html            エントリーポイント
├── css/
│   └── style.css         スタイル(ダークテーマ、色相環、モーダル等)
├── js/
│   ├── utils.js           汎用ヘルパー
│   ├── color.js           HEX→HSL変換など色の計算
│   ├── avatar.js          画像未設定時のプレースホルダー生成
│   ├── db.js               IndexedDBラッパー
│   ├── state.js             状態管理(Store)
│   ├── sampleData.js         初回投入用サンプルキャラクター
│   ├── iacharaSync.js         いあきゃら連携(ブックマークレット方式)
│   ├── wheel.js                色相環の描画・配置ロジック
│   ├── hoverCard.js             ホバー時の簡易情報カード
│   ├── detailModal.js            クリック時の詳細モーダル
│   ├── characterForm.js           新規追加・編集フォーム
│   ├── tagFilter.js                タグ絞り込みUI
│   ├── importExport.js             JSONエクスポート/インポート
│   └── main.js                      起動処理
└── tools/
    └── static-server.ps1    ローカル確認用の簡易サーバー(PowerShell)
```

各機能が別ファイルに分かれているため、機能追加や修正がしやすい構成にしてあります。

## 「いあきゃら」連携について

いあきゃらには公式API(2026年8月時点。準備中の様子はあります)が無いため、URLを入力するだけで
自動取得する機能は実装していません。代わりに「ブックマークレットでいあきゃら側から情報を取り出し、
JSONとして貼り付ける」方式を実装しています。詳しい使い方は上の「いあきゃらからの取り込み」を参照してください。

- 取得できる項目: 名前・カラー・立ち絵・職業・年齢など、公開シートページに表示されている項目
- 取得できない項目: タグ・シナリオ・HO(公開シートページには含まれないため手動入力)
- 将来、公式APIが提供された場合は `js/iacharaSync.js` の `fetchFromIachara` を実装することで、
  URL入力だけの自動取得に置き換えられる構造にしてあります。

データ構造(`color` / `tags` / `name` / `image` / `iacharaUrl` など)は、
外部データが入ってきてもそのままマージできる形にしてあります。
